# Project Instructions for AI Agents — InterviewGenie AI

## 1. MANDATORY: Codebase Knowledge Graph (`graphify`)
This repository has an active, persistent knowledge graph generated by `graphify` located at `graphify-out/`.

**Rules for all agents (Frontend, Backend, AI, Media, QA, Research):**
1. **Never perform blind full-repository scans or multi-directory searches.**
2. **Always query the knowledge graph first** to explore architecture, dependencies, routes, and call flows:
   - **Query context:** `python -m graphify query "<question>"` (uses BFS/DFS graph traversal to locate relevant symbols and files without reading entire files).
   - **Trace connections:** `python -m graphify path "<SymbolA>" "<SymbolB>" --undirected` to trace exact call, import, or data flow paths.
   - **Inspect components:** `python -m graphify explain "<Symbol>"` to inspect a class, function, or service and its immediate neighborhood.
   - **Section lookups:** `python -m graphify section "<Heading>"` to read targeted documentation sections.
3. **Consult `graphify-out/GRAPH_REPORT.md`** for architectural summaries, god nodes, and community boundaries.
4. **Update graph after code modifications:** When you add, modify, or delete code symbols, run `python -m graphify update .` to update the AST graph incrementally (fast, AST-only, zero token cost).
